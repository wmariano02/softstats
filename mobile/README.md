# Mobile - SoftStats CJB

Frontend Flutter 3.x para la gestión de estadísticas deportivas.

## 📁 Estructura

```
mobile/
├── lib/
│   ├── main.dart
│   ├── screens/
│   ├── widgets/
│   ├── services/
│   ├── providers/
│   ├── models/
│   ├── utils/
│   └── config/
├── assets/
│   ├── images/
│   └── icons/
├── test/
└── pubspec.yaml
```

## 🚀 Inicio Rápido

```bash
cd mobile
flutter pub get
flutter run
```
